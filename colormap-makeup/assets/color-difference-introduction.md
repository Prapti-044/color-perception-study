## Color Difference Perception Task Tutorial

### What You'll Be Asked

In the upcoming tasks, you'll see **pairs of colored circles**. To illustrate same versus different colors, we've isolated colors for the next three questions. You will be asked:

**"Are the two colors the same or different?"**

You'll have two options:
- **Same** - if the circles appear to be identical in color
- **Different** - if you can see **any** difference between the colors

### How It Works
1. Select **Same** or **Different**.  
2. Click **Check Answer**.  
   - If wrong, you’ll get up to **2 more tries**.  
3. Once correct, click **Next** to continue.
